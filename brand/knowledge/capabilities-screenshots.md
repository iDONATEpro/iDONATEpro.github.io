# Capabilities / marketing screenshots

Central spec for product UI shots used on `/capabilities/` and brand composites. All assistants: follow this; Graphics Designer craft-checks annotated shots before Forrest sees them.

## File type
- **PNG** (RGB). Keeps UI text sharp.
- Do **not** use JPEG/WebP for CRM UI screenshots.
- SVG is for icons only — not screenshots.

## Dimensions
| Use | Size | Notes |
|---|---|---|
| Preferred product shot | **1280 × 800** | Or **1280 × 656** hero crop of the CRM chrome |
| Page display target | ~**1200 × 750** | Markup aspect (~16:10); we scale in layout |
| Tall lists / reports | **~1265 × 1100–2200** | Full-page OK; layout crops/scales |
| Annotated composite | up to **1480 × 900** | Overlays on the product shot (Intercom-style bar) |

Retina 2× captures are fine — we downscale. Consistent ~1280 width is the bar; exact match to old files is not required.
